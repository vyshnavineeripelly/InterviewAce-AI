# InterviewAce AI — Phase 1

MERN scaffold with a Vite React frontend and an Express backend. MongoDB and authentication are not connected yet.

## Prerequisites

- Node.js 18+
- npm
- Git

## Commands (Windows / PowerShell)

From `interviewace-ai`:

```powershell
npm run install:all
npm run dev:server
npm run dev:client
```

Run `dev:server` and `dev:client` in two separate terminals.

- Frontend: http://localhost:5173
- Backend health: http://localhost:5000/api/health
